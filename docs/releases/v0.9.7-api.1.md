# Historical upstream-derived release note: Handy API Edition v0.9.7-api.1

This historical release note records the first public build of the
community-maintained API Transcription Edition, based on upstream Handy v0.9.7.
It predates the Vozel name and is retained for provenance; it does not describe
the current Vozel brand or distribution.

## Highlights

- Optional low-latency transcription with the Groq and OpenAI presets.
- A single active transcription engine: API providers are shown as active only
  while API Transcription is selected; choosing a local model disables remote
  transcription without deleting the saved endpoint configuration.
- Custom OpenAI-compatible `/audio/transcriptions` endpoints.
- API keys stored in the operating system credential store, not settings files.
- HTTPS enforcement for remote endpoints, redirect blocking, bounded responses
  and strict response validation.
- More resilient Linux shortcuts and faster X11 text entry.
- Optional smart-paste helper for terminals, browsers, chats and regular text
  fields on X11.

## Install on Debian / Ubuntu x86_64

Download `Handy_API_Edition_0.9.7-api.1_amd64.deb` and `SHA256SUMS` from this
release. From the download directory, verify and install it with:

```bash
sha256sum --check SHA256SUMS
sudo apt install ./Handy_API_Edition_0.9.7-api.1_amd64.deb
```

After installation, open **Settings → Models → API transcription**, edit the
Groq preset, enter your API key, test the connection and select **Use**. The API
key is stored by the operating system credential service.

## Important privacy information

Local transcription remains available and keeps audio on the computer. API
Transcription sends each completed recording to the selected provider, whose
privacy, retention and billing policies apply. Remote mode is opt-in.

Automatic updates are disabled in this build because the fork does not yet
operate a signed update channel. Future fork releases must be installed
manually from this repository.

This is an independent community fork and is not an official upstream Handy
release.
