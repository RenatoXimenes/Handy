# Vozel 0.1.0

Vozel is an independent desktop dictation app built from the open-source Handy
codebase. It has its own name, icon, application identifier and support channel.

This release keeps local transcription and adds optional Groq, OpenAI and custom
OpenAI-compatible API transcription. Remote mode sends audio to the selected
provider; local mode keeps the recording on your computer.

Nemotron 3.5 ASR PT-BR is an optional local download for Brazilian Portuguese.
The model is not bundled with the application.

Automatic updates remain disabled until Vozel has its own signed update feed.
